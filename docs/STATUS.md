## Gotchas (max 8, one line each; delete when fixed)
- PICO-8 `sin`/`atan2` are y-inverted: `sin(0.25) = -1`, `atan2(0,-1) = 0.25`.
- Board values are `u16`: pop states reach ~609 (`colour + 10*pop + 300`), so `u8`
  overflows. A cell is settled only while `v < 10`.
- `neighbors()` wraps the last column into the next row and never bounds `y`
  upward; both quirks are the cart's and are preserved on purpose.
- `src/consts.rs` is generated by `tools/extract_level.py`; edit the tool, not it.
- `assets/upstream/*` is gitignored on purpose (No License).
- `cargo run` needs a display; the container has none, so visual proof comes from
  `cargo run --bin shot` + the PNG.
- The cart has no `b2cell` function, despite the plan's M2.1 naming one.
