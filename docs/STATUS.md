## Gotchas (max 8, one line each; delete when fixed)
- **Never commit `assets/upstream/`** — the cart is "No License"; the repo had to
  be rebuilt once to purge it from history.
- PICO-8 `sin`/`atan2` are y-inverted: `sin(0.25) = -1`, `atan2(0,-1) = 0.25`.
- Board values are `u16`: pop states reach ~609, so `u8` overflows; settled = `v < 10`.
- Torque from 0.05 hits zero after **110** frames, not the 60 the plan guessed.
- `S`/space is a debug spin key, not a cart button — delete it when M4 adds firing.
- `circfill` is `dx²+dy² <= r²` (matches PICO-8 at r=0,1,4); placeholder until sprites.
- `neighbors()` wraps the last column into the next row, and never bounds `y` upward.
- `src/consts.rs` is generated by `tools/extract_level.py`; edit the tool, not it.
